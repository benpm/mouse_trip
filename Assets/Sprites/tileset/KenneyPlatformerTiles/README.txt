Kenney New Platformer Pack - Unity import
==========================================

Generated by the Kenney tilesheet tool (tile size 64 px, pixels-per-unit 64).

1. Copy the KenneyPlatformerTiles folder into your project's Assets/ folder.
2. RuleTiles.asset and AnimatedTiles.asset need com.unity.2d.tilemap.extras (Package Manager).
3. Terrain RuleTiles: sand, stone, lab, concrete, lead_pipe (16-combo blob rules each).

Tiles, AnimatedTiles and RuleTiles are packed as SUB-ASSETS of single .asset files
(expand Tiles.asset in the Project window to reach individual tiles).
GUIDs and sprite internalIDs are deterministic hashes of tile names.
