Kenney New Platformer Pack - Backgrounds sheet
==============================================

Generated by the Kenney tilesheet tool (tile size 256 px).
Plain sprite collection (no terrain autotiling). 0 animated tile(s).

Tiles are packed as sub-assets of a single Tiles.asset (expand it in the Project window).
Unity: copy the KenneyPlatformerBackgrounds folder into Assets/. AnimatedTiles.asset needs com.unity.2d.tilemap.extras.
Tiled: keep the .tsx next to its .png.
